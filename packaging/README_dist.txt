失敗写真チェッカー（PhotoCull） v1.0
=====================================

たくさんの写真を読み込んで、ピンボケ・手ブレ・露出の失敗などを自動で見つける
Windows 用のアプリです。インストールは不要で、インターネットにも接続しません
（写真はすべてこの PC の中だけで処理されます）。


■ 動作環境
  - Windows 10 / 11（64 ビット）
  - メモリ 8GB 以上を推奨
  - グラフィックボード（GPU）があれば自動で使って速くなります（NVIDIA / AMD / Intel）。
    無くても CPU で動きます。


■ 起動のしかた
  1. この ZIP ファイルを右クリック →「すべて展開」で、好きな場所に展開する
     （ZIP の中のまま起動すると動かないことがあります）
  2. PhotoCull.exe をダブルクリックする
     - 起動に 10〜20 秒ほどかかります（毎回、中身を一時フォルダに展開するため）
     - 「Windows によって PC が保護されました」と表示されたら、
       「詳細情報」→「実行」を押してください（署名のない個人作成のアプリのため表示されます）


■ 使い方（かんたんに）
  1. 「フォルダを開く」を押すか、写真やフォルダをウィンドウにドラッグ＆ドロップする
  2. 解析が終わると、失敗写真に赤い枠と理由が表示される
     - 上の「表示」で理由ごとに、「タグ」で写っている物（人物・サーフボード・犬など）ごとに絞り込める
     - 写真を選んで F キーで「失敗」、G キーで「OK」に手動で変更できる
  3. 「失敗写真を移動・コピー」または「OK の写真を移動・コピー」で、別のフォルダへ振り分ける
     - 同じ名前の RAW ファイル（.RAF / .NEF / .CR3 / .ARW など）も一緒に移動できる
     - 移動した直後なら「移動を元に戻す」（Ctrl+Z）で元に戻せる
  4. 判定の厳しさは、左側のパネルで調整できる

  対応形式: JPG / PNG / BMP / TIFF / WebP（RAW は判定しません。同じ名前の JPG があれば一緒に動かせます）


■ 写真の安全について
  - アプリが写真を削除することはありません。
  - 写真の場所が変わるのは、「移動」を選んで確認画面で「はい」を押したときだけです。
  - 移動先に同じ名前の写真があっても上書きせず、名前に番号を付けます。


■ 削除のしかた
  このフォルダを削除するだけです。
  設定はレジストリの HKEY_CURRENT_USER\Software\PhotoCull に、
  エラーの記録は %LOCALAPPDATA%\PhotoCull に残ります（どちらも消して構いません）。


■ うまく動かないとき
  %LOCALAPPDATA%\PhotoCull の中の error.log / crash.log を作者に送ってください。
  GPU が使えているかは、画面右下の「AI処理: GPU / CPU」の表示で分かります。
